
# Project Notebooks

This folder contains the Jupyter notebooks supporting the data science projects in this portfolio.

## spotify_analysis.ipynb
Python exploratory data analysis of Spotify track metadata.

The notebook should not contain API credentials. Reproducing the original API collection may require valid Spotify developer access.

## ml_project.ipynb
County-level housing value prediction using U.S. Census ACS data, linear regression, and random forest regression.

Model evaluation results are preliminary until Census missing-value codes have been validated and the analysis rerun.

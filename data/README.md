
# Project Datasets

This folder contains CSV files supporting the projects in this portfolio.

## spotify_tracks.csv
Track-level metadata collected through the Spotify Web API for exploratory analysis.

## county_data_clean.csv
County-level socioeconomic and housing data sourced from the 2023 U.S. Census American Community Survey five-year estimates.

Note: Census missing-value codes and feature calculations require further validation before this dataset should be considered fully cleaned.

## model_comparison.csv
Model evaluation results from the county home value prediction project.

Note: These results are preliminary and require revalidation after the Census data-quality review.

Predicting U.S. County Home Values

Exploring how income, population, and educational attainment relate to county-level median home values using U.S. Census data and supervised machine learning.

01 · Overview

Project Summary

Housing values vary considerably across U.S. counties. This project investigates whether selected socioeconomic indicators can help explain and predict county-level median owner-occupied home values.

Using the 2023 American Community Survey five-year estimates, I assembled a dataset containing 3,216 county and county-equivalent records and compared multiple regression approaches.

The project emphasizes the complete modeling workflow: data collection, cleaning, feature preparation, model training, evaluation, and interpretation.

02 · Research Question

Can Socioeconomic Data Predict Home Values?

The central question is whether county-level median household income, population, and bachelor's degree attainment can provide useful predictive information about median owner-occupied home values.

This is a predictive modeling exercise, not a causal analysis. Relationships between the variables do not establish that changes in any single feature cause changes in housing prices.

03 · Dataset

Data Collection & Features

Data Source

U.S. Census Bureau, 2023 American Community Survey five-year estimates, accessed through the Census API.

3,216 county and county-equivalent records

Target Variable

Median value of owner-occupied housing units at the county level.

Predictor Variables

Median household income, population, and percentage of adults with a bachelor's degree or higher.

Preparation

Converted API responses into numeric variables, prepared model features, and evaluated data quality before model training.

04 · Modeling

Models Compared

Mean Baseline

A simple reference model that predicts the average training-set home value. This establishes a baseline for evaluating more sophisticated methods.

Linear Regression

Models home values as a linear combination of the selected socioeconomic predictors. Provides an interpretable comparison against the baseline.

Random Forest Regression

An ensemble of decision trees that can capture nonlinear relationships and interactions among predictors.

Evaluation

Compared predictive performance using root mean squared error (RMSE) and coefficient of determination (R²).

05 · Results

Model Evaluation

Preliminary Findings

The original project reported stronger predictive performance from random forest regression than from linear regression. However, the source data requires an additional quality-control review.

Some Census API fields can contain special negative codes representing missing or unavailable estimates. These must be handled correctly before the final model metrics can be considered reliable.

Final RMSE and R² results pending data-quality verification and model rerun.

Once the dataset has been validated and the models rerun, this section will report the confirmed performance metrics.

06 · Interpretation

What the Project Demonstrates

The project demonstrates how public socioeconomic data can be integrated into a supervised machine learning workflow.

It also illustrates why data validation is essential: a model can produce numerical evaluation metrics even when the underlying dataset contains invalid or missing-value codes.

A responsible modeling process requires checking source values, verifying feature calculations, and confirming that reported performance is reproducible.

07 · Limitations

Important Considerations

  • County-level aggregates do not represent individual households or properties.
  • The model uses a limited number of socioeconomic predictors.
  • Census estimates have sampling uncertainty and may contain missing or suppressed values.
  • Geographic variation and omitted factors may influence model accuracy.
  • The analysis identifies predictive associations, not causal effects.
  • Final performance claims require rerunning the models after data validation.

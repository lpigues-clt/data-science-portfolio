Data Quality · Machine Learning

Why Data Validation Comes Before Model Accuracy

My county home value prediction project highlighted the importance of checking source data before trusting model metrics. Census API datasets can contain special missing-value codes that require careful treatment during cleaning.

A high R² score is only meaningful when the dataset, feature calculations, and evaluation process are valid. My next step is to rerun the analysis after verifying those inputs.

APIs · Exploratory Analysis

What a Small Spotify Dataset Can—and Cannot—Tell Us

My Spotify project used a sample of 50 tracks to explore explicit-content labels, duration, and release-date metadata. It gave me experience collecting data through an API and analyzing it with Python.

It also reinforced the importance of sampling limitations. Search results are not a random sample of all music, and unavailable popularity fields prevent conclusions about whether explicit tracks are more popular.

My Approach

Principles I Apply to Data Projects

Start With a Clear Question

Define what the analysis is trying to answer before selecting techniques or building models.

Understand the Data

Examine sources, missing values, distributions, and potential biases before interpreting results.

Compare Against a Baseline

Evaluate whether a more complex method provides meaningful improvement over a simpler alternative.

Communicate Limitations

Explain what findings support, what remains uncertain, and what additional work is needed.
